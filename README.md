# אביחי משימות — Avihai Tasks

אפליקציית **PWA** לניהול פרויקטים ומשימות בתחום תשתיות אנרגיה. בעברית, RTL מלא,
מתקינה כאפליקציה במכשיר ועובדת גם ללא חיבור לאינטרנט.

> קובץ אחד (`index.html`), Vanilla JS, ללא ספריות ו-ללא שלב build. הנתונים מסונכרנים
> בענן דרך Firebase Firestore, כך שהם זמינים בכל המכשירים ולא נמחקים בניקוי הדפדפן.

---

## יכולות עיקריות

- **דשבורד** — מיון חכם של משימות לפי דחיפות, חשיבות ואיחור.
- **פרויקטים → תחומים → משימות** — היררכיה עם סטטוס, אחראי, עדיפות, חשיבות ותאריך יעד.
- **פתקים** עם קנבס לכתב יד (ציור באצבע/עט, ביטול, צבעים).
- **עוזר AI** — מעדכן משימות בשפה חופשית (Anthropic API).
- **סנכרון Google Calendar** — דו-כיווני, ללוח שנה ייעודי.
- **חיפוש, גרירה-ושחרור, מצב כהה, ייצוא CSV/JSON.**
- **גיבוי ושחזור** — ראו למטה.

---

## גיבוי ושחזור (חדש)

הנתונים החיים נשמרים במסמך יחיד ב-Firestore. כדי להגן מפני מחיקה בטעות או מפעולת AI
שמוחקת פרויקט, האפליקציה שומרת **גרסאות (snapshots)** במסמך נפרד:

- **גיבוי אוטומטי** פעם ביום לענן (נשמרים 12 הגיבויים האחרונים).
- **גבה עכשיו** — יצירת גיבוי ידני מיידי.
- **שחזור** — חזרה לכל גרסה קודמת (המצב הנוכחי מגובה אוטומטית לפני השחזור).
- **הורד / טען קובץ** — גיבוי מלא של כל הנתונים לקובץ JSON, ושחזור ממנו.

הגישה לכל אלה דרך הכפתור **🛡️ גיבוי ושחזור** בסרגל הצד.

## הרצה מקומית

זהו קובץ סטטי — מספיק שרת קבצים פשוט (נדרש כדי שה-Service Worker יעבוד):

```bash
python3 -m http.server 8000
# גלשו אל http://localhost:8000
```

## הגדרות (אופציונלי)

מפתחות נשמרים ב-`localStorage` של הדפדפן בלבד — לא בקוד ולא בשרת:

| יכולת | מה צריך | איפה |
|---|---|---|
| עוזר AI | מפתח Anthropic API (`console.anthropic.com`) | כפתור 🔑 בעמוד ה-AI |
| Google Calendar | OAuth Client ID + API Key (Google Cloud Console) | חיבור Google Calendar |

## ארכיטקטורה בקצרה

- **State** — אובייקט `S` ({projects, notes, ...}) בזיכרון.
- **אחסון** — `sv()` כותב את `S` ל-Firestore (`data/avihai`); `onSnapshot` מסנכרן
  בזמן אמת לכל המכשירים.
- **גיבויים** — מסמך נפרד (`data/avihai_backups`) עם רשימת snapshots מתגלגלת.
- **API keys / הגדרות Google** — `localStorage`.

> הערה: קריאות ה-AI נשלחות ישירות מהדפדפן ל-Anthropic עם המפתח של המשתמש. מתאים
> לשימוש אישי; לשיתוף ציבורי מומלץ proxy בצד שרת כדי לא לחשוף את המפתח.
